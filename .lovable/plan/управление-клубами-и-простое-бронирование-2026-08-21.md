# Управление клубами и простое бронирование

Четыре зоны улучшений: супер-админ, владелец клуба, игрок, гость. Данные по-прежнему в mock-базе (`src/lib/mock-db.ts` + `src/lib/store.tsx`), без бэкенда.

## 1. Админ: управление клубами и владельцами

Вкладки на `/admin`:

- **Клубы** — таблица с поиском и фильтром по статусу. Действия по каждому клубу: одобрить/отклонить заявку, приостановить/восстановить, сменить тариф (Trial/Start/Pro/Network), изменить владельца, открыть карточку клуба.
- **Карточка клуба (диалог)** — админ видит и правит те же поля, что владелец: название, адрес, часы работы, зоны и цены, количество мест, статус.
- **Владельцы** — список пользователей с ролью owner: имя, телефон, email, его клубы, количество бронирований. Действия: создать владельца, назначить/переназначить клуб, заблокировать (suspend всех его клубов), сменить роль.
- **Создание клуба вручную** — админ может завести клуб и сразу привязать владельца.

## 2. Владелец: конструктор клуба

Новая вкладка «Мой клуб» на `/partner` с полноценным CRUD:

- **Комнаты/зоны**: добавить, переименовать, удалить, задать тип (Standard, VIP, PS5, Bootcamp, VR), цену за час, описание.
- **Компьютеры/места**: внутри зоны — список мест с номером, названием (PC-01), характеристиками (CPU, GPU, RAM, монитор, Гц), статусом (свободен / в ремонте / отключён). Кнопки «Добавить ПК», «Дублировать», «Удалить», «Добавить N мест сразу».
- **Профиль клуба**: название, адрес, часы работы, телефон, обложка и фото, удобства (кафе, PS5, стриминг, паркинг).
- Всё сразу отражается в сетке мест на странице клуба у игрока.

Для этого расширяем модель: `PcZone` получает поле `amenities`/описание, добавляется таблица `seats` (id, zoneId, номер, название, характеристики, статус) вместо простого счётчика мест.

## 3. Игрок: бронирование в 3 шага

- На главной — крупный блок «Забронировать сейчас»: город/поиск, фильтры (тип зоны, цена, свободно сейчас), карточки клубов со свободными местами прямо сейчас.
- На странице клуба — один экран-визард: **Зона → Время → Место**, с выбранной суммой в липкой нижней панели и кнопкой «Забронировать». Меньше текста, крупные кнопки, всё в один скролл на мобиле.
- Быстрое повторное бронирование: на `/profile` кнопка «Повторить» у прошлой брони — сразу подставляет клуб/зону/место.
- После оплаты — экран с кодом HP-XXXX и кнопкой «Добавить в календарь»/«Скопировать код».

## 4. Гость: бронь без регистрации

- Гость проходит тот же визард без входа. На шаге оплаты — мини-форма: имя + телефон (email не обязателен).
- Оплата мок-методом → экран подтверждения с кодом HP-XXXX, клубом, зоной, местом и временем; код можно скопировать.
- Гостевая бронь сохраняется в store с `guestName`/`guestPhone` и без `userId`, попадает в «Входящие брони» владельца наравне с остальными.
- Ссылка «Проверить бронь по коду» — ввод кода показывает детали брони (для гостя без аккаунта).
- Ненавязчивое предложение «Создать аккаунт, чтобы копить часы» после подтверждения — без блокировки.

## Технические детали

- `src/lib/mock-db.ts`: новый тип `Seat`, поля характеристик, `Booking.guestName`/`guestPhone`, `Booking.userId` становится опциональным.
- `src/lib/store.tsx`: методы `addZone`, `updateZone`, `removeZone`, `addSeat`, `updateSeat`, `removeSeat`, `addClub`, `assignOwner`, `setClubPlan`, `addGuestBooking`, `findBookingByCode`.
- `src/routes/admin.tsx`: разбить на вкладки (Обзор / Клубы / Владельцы / Транзакции), диалоги редактирования.
- `src/routes/partner.tsx`: вкладка «Мой клуб» с редактором зон и ПК.
- `src/routes/clubs.$clubId.tsx`: переделать в пошаговый визард с гостевой оплатой.
- `src/routes/index.tsx`: блок быстрого бронирования и фильтры.
- Новый маршрут `/booking/$code` — проверка брони по коду.
- Все новые строки добавляются в `src/lib/i18n.tsx` (RU / KK / EN).
